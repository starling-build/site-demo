# Starling User Guide

A tour of the desktop: what you see at first login, how to move around, the
keyboard shortcuts, the apps, and how to install more. If Starling is not yet
installed, start with the Installation Guide.

Starling's interaction model is close to macOS — if you have used a Mac, most
of this will feel familiar.

## How this guide is organised

1. **Getting in** — [Choosing Starling at login](#choosing-starling-at-login)
   and [First login](#first-login).
2. **The desktop** — [The dock](#the-dock), [The Launchpad](#the-launchpad),
   [The menu bar](#the-menu-bar), [Windows](#windows),
   [Spaces and Mission Control](#spaces-and-mission-control) and
   [Right-click the desktop](#right-click-the-desktop).
3. **Features** — [Recording the screen](#recording-the-screen),

4. **Reference** — [Keyboard shortcuts](#keyboard-shortcuts),

5. **When something is off** —
   [Things to know in this release](#things-to-know-in-this-release) and
   [When the terminal draws the wrong thing](#when-the-terminal-draws-the-wrong-thing).

Every section name in this guide is a link: tap it to jump there, and use
**Contents** to come back.

## Conventions

| You see | It means |
|---|---|
| **Ctrl + ↑** | Hold the first key and press the second |
| **Settings → Appearance** | Open Settings, then its Appearance section |
| `~/Videos` | A path, command or file name, exactly as typed |
| A quoted note like the one below | Something worth knowing before you go on |

> **Note.** Starling is an early preview. The limits that will matter most are
> listed in [Things to know in this release](#things-to-know-in-this-release);
> read that section first if you plan to rely on the desktop every day.
