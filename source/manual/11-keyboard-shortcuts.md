# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| **Ctrl + →** / **←** | Adjacent [space](#spaces-and-mission-control) |
| **Ctrl + Shift + →** / **←** | Move focused window to adjacent space |
| **Ctrl + Tab** | Cycle spaces |
| **Ctrl + ↑** | [Mission Control](#spaces-and-mission-control) |
| **Ctrl + ↓** | [Workspace mode](#workspaces-a-desktop-for-your-agent) |
| **Ctrl + Shift + R** | Start / stop [screen recording](#recording-the-screen) |
| **Ctrl + Shift + S** | Show the [screensaver](#the-screensaver) now |
| **Ctrl + Space** | Toggle the input method (fcitx5, for CJK and other IME input) |
| **Esc** | Close Mission Control; release a taken-over [agent window](#workspaces-a-desktop-for-your-agent) |
| Double-click title bar | Maximize / restore a [window](#windows) |

`Ctrl` + arrows belong to the system — apps never see them — so they work no
matter which window is focused.
